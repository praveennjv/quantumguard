# Changelog

## 0.1.0 — 2026-08-20

Milestone 1–2 MVP:

- Repository layout (modular monolith)
- CLI: `scan`, `version`, `rules`
- Java / Python / JavaScript / TypeScript adapters (AST)
- Detectors for RSA, ECC, DH, hashes, symmetric, JWT, TLS, certs, KDFs
- Versioned risk models v1–v4 and HNDL assessment
- JSON, SARIF, CycloneDX CBOM, CSV, HTML
- GitHub Action (local path `integrations/github/scan`)
- CI policy gate and baseline support
